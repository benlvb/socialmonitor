# Code of conduct

## The short version

Be decent to each other. Assume good faith, critique ideas rather than people,
and accept that maintainers may say no to a change without it being personal.

## Not acceptable

Harassment, personal attacks, discriminatory language, sustained disruption of
discussions, publishing others' private information, or any behaviour that
would make a reasonable person uncomfortable participating.

## Scope

This applies in issues, pull requests, discussions, and any other space where
you are participating in this project.

## Enforcement

Report problems privately through the repository's **Security** tab
(**Report a vulnerability** also works for conduct reports and is the only
private channel this repo has) or by contacting the maintainer through their
GitHub profile. Reports are handled confidentially.

Maintainers may edit, hide, or delete contributions that violate this
document, and may block repeat offenders. There is no appeals process; this is
a small project run by volunteers.
